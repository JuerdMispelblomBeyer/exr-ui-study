# Infrastructure health — sparse black tile grid

## Reference identity and evidence quality

- Source: `reference/ref-030__dark-infrastructure-health__live-telemetry.jpeg`.
- Type: direct dark infrastructure-health concept.
- Evidence: high for low-relief surface treatment and metric hierarchy; low for complex workflow, navigation, and diagnostic depth.

## Executive design reading

A black gridded field supports two wide metrics and four smaller health tiles.
Subtle edge lighting and green badges make it elegant, but the design is too
sparse and too close to a generic premium metric grid to guide a full system.

## Dimension analysis

### IH-AES-01 — Aesthetic and personality

**OBSERVATION** — Black metric tiles emerge subtly from a gridded background via
soft edge light.

**INTERPRETATION** — The design feels refined because contrast is calibrated,
not because its composition is distinctive.

**TRANSFERABLE PRINCIPLE** — Use low-relief edge stacks for persistent technical
surfaces, provided readability survives without atmosphere.

### IH-COMP-01 — Composition, grid, and alignment

**OBSERVATION** — Two large tiles sit above four equal small tiles under a title.

**INTERPRETATION** — Size creates a basic hierarchy, but symmetry and repetition
make the screen static.

**TRANSFERABLE PRINCIPLE** — Vary spans according to active system relationships
and allow the selected/faulted path to reshape emphasis.

### IH-DEN-01 — Density and whitespace

**OBSERVATION** — Large surfaces hold one number and a short label each.

**INTERPRETATION** — The view reads instantly but wastes space needed for
engineering evidence.

**TRANSFERABLE PRINCIPLE** — Keep the clarity of large state readings while
embedding compact thresholds, freshness, source, and short trends.

### IH-TYPE-01 — Typography and hierarchy

**OBSERVATION** — Large values and a clean page heading dominate; qualifiers are
small and grey.

**INTERPRETATION** — Value hierarchy is clear, though generic and potentially
under-specified.

**TRANSFERABLE PRINCIPLE** — Pair every large value with unit, threshold, time
window, and source; use display type sparingly.

### IH-COLOR-01 — Color and contrast

**OBSERVATION** — Green badges are the only saturated elements.

**INTERPRETATION** — Color scarcity is strong, but green-only healthy status
needs text/icon redundancy.

**TRANSFERABLE PRINCIPLE** — Preserve scarce semantic color and reserve ExR
yellow for current/action, with explicit state labels.

### IH-GEO-01 — Geometry, borders, shadows, and surfaces

**OBSERVATION** — Repeated rounded tiles use gradients and inner/outer shadows
instead of clear borders.

**INTERPRETATION** — Low relief is elegant but can reduce exact edge perception
and become generic “soft UI.”

**TRANSFERABLE PRINCIPLE** — Use calibrated contour/edge stacks on a few chassis
surfaces, with sharper dividers inside dense instruments.

### IH-IMG-01 — Imagery and iconography

**OBSERVATION** — No topology, chart, real image, or equipment representation is
shown.

**INTERPRETATION** — The interface states results without showing cause or
evidence.

**TRANSFERABLE PRINCIPLE** — Treat large metrics as supporting annotations to a
truthful system model, not the entire overview.

### IH-HIER-01 — Information hierarchy, interaction, and motion

**OBSERVATION** — Tiles appear clickable and badges indicate status; no drill-
down or animation is evidenced.

**INTERPRETATION** — The likely flow is metric selection, but there is no visible
causal sequence.

**TRANSFERABLE PRINCIPLE** — Make each summary state visibly connect to the node,
path, trace, and action it governs.

### IH-DIST-01 — Distinctive decisions and limits

**OBSERVATION** — Soft black tile craft is the main identity cue.

**INTERPRETATION** — The style is aesthetically polished but common in concept
dashboards.

**TRANSFERABLE PRINCIPLE** — Borrow its restraint and edge calibration; reject
its anonymous metric-grid composition.

## Signature moves

| Move | Why it works | Transfer | Do not copy |
|---|---|---|---|
| Low-relief edge stack | Creates refined dark depth | Chassis and inset diagnostic surfaces | All-soft card field |
| Two-size hierarchy | Gives fast overview | Dominant platform state + compact evidence | Fixed 2+4 layout |
| Scarce semantic badges | Protects color meaning | Labeled status chips | Green dot alone |
| Grid substrate | Suggests calibrated structure | Very subtle instrument alignment grid | Decorative graph paper |
| Large readings | Supports glanceability | Safety/network/compute state when selected | Metric-only overview |

## Translation decisions

- **Borrow:** restrained palette, edge calibration, clear value hierarchy,
  scarce semantic color.
- **Ignore:** six-tile composition, sparse metric-only content, exact grid.
- **Brand-specific:** source typography and soft-black material recipe.
- **Accidental:** crop does not show navigation or detailed states.
- **Anti-patterns/limitations:** generic premium metric grid; excessive rounded
  rectangles; poor density; symmetric template feel; weak causal evidence;
  subtle contrast may fail accessibility.
