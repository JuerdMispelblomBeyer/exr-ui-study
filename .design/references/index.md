# UI reference analysis index

This index covers every UI inspiration source currently in `reference/`.
Exact duplicates, renamed copies, and alternate crops from the same design family
are consolidated into one logical analysis; every contributing filename is
listed in that analysis. The original reference files remain unchanged.

## Cross-reference orientation

- **Best composition sources:** system-performance spatial map, urban-sound
  monitor, home-energy instrument grid, logistics workbench, grey wireframe.
- **Best evidence/craft sources:** dense energy chart grid, dark analytics chart
  probe, resource utilization instrument, logistics matrix.
- **Best continuity sources:** guided quiz flow, treatment timeline, green active
  ribbon, incident map.
- **Best surface/material sources:** dimensional instrument family, home-energy
  inversion grid, frosted workflow shell, infrastructure-health edge stack.
- **Useful baselines, not art direction:** Lunar family, compute regional health,
  cloud monitoring, industrial IoT, light network monitor, facility comparison.
- **Presentation-only influence:** editorial turbine app; use for explanation,
  onboarding, and documentation rather than daily monitoring composition.
