## Executive design reading

This family demonstrates disciplined dark-mode density. A stable navigation
rail frames a continuous workbench whose modules share quiet geometry; visual
priority comes from span, position, and content type more than color.

## Dimension analysis

### LUN-AES-01 — Overall aesthetic and personality

**OBSERVATION** — The family uses charcoal layers, thin separators, muted type,
and repeated folder/document objects.

**INTERPRETATION** — It feels systematic and durable because no region depends on
a high-saturation flourish.

**TRANSFERABLE PRINCIPLE** — Build long-session dark interfaces from controlled
luminance tiers and consistent content objects rather than decorative effects.

### LUN-COMP-01 — Composition, grid, alignment

**OBSERVATION** — A fixed left rail frames KPI strips, a chart/list row, and a
document-card row; crops preserve shared axes and spans.

**INTERPRETATION** — The system reflows predictably and establishes strong family
consistency, though the composition remains conventional.

**TRANSFERABLE PRINCIPLE** — Preserve a stable chassis and aligned workbench grid
across viewports, but let product-specific evidence—not a KPI row—define focus.

### LUN-DEN-01 — Density and whitespace

**OBSERVATION** — Nearly every region carries information; spacing and card
padding are consistent and compact.

**INTERPRETATION** — The viewport is efficient, but uniform density and repeated
anatomy flatten priority.

**TRANSFERABLE PRINCIPLE** — Retain compact spacing for routine work while
creating deliberate sparse zones around selected or anomalous evidence.

### LUN-TYPE-01 — Typography and hierarchy

**OBSERVATION** — Values are large; section headings medium; navigation and body
copy remain small and low contrast.

**INTERPRETATION** — The type ladder is reliable but generic; content hierarchy
is carried mainly by scale and position.

**TRANSFERABLE PRINCIPLE** — Use a compact production-safe ladder, then add one
distinct technical role for system identity and machine data.

### LUN-COLOR-01 — Color and contrast

**OBSERVATION** — White/grey define the interface; blue/yellow folder markers and
avatars supply tiny localized color.

**INTERPRETATION** — Luminance does most structural work, so the design remains
coherent in greyscale.

**TRANSFERABLE PRINCIPLE** — Build surface hierarchy in neutral values and reserve
the brand accent for current scope and action.

### LUN-GEO-01 — Geometry, borders, shadows, surfaces

**OBSERVATION** — Moderate rounded cards use thin borders; folder illustrations
are inset and slightly dimensional; elevation is restrained.

**INTERPRETATION** — Consistent geometry supports family cohesion but risks a
one-box-per-concept habit.

**TRANSFERABLE PRINCIPLE** — Reuse edge and radius grammar, but merge related
evidence into continuous surfaces where relationships matter.

### LUN-IMG-01 — Imagery and iconography

**OBSERVATION** — Stylized folder/document objects and avatars visually identify
contracts and ownership; line icons label navigation.

**INTERPRETATION** — Small object imagery gives otherwise abstract records a
tactile identity.

**TRANSFERABLE PRINCIPLE** — Use compact, consistent object glyphs for real
platform entities; avoid decorative 3D assets without operational meaning.

### LUN-HIER-01 — Information hierarchy, interaction, motion

**OBSERVATION** — Search, folders, date scope, share/edit, export, and expandable
navigation are visible; no motion is shown.

**INTERPRETATION** — Actions are mostly local and predictable. The page title and
KPI strip compete weakly with the chart.

**TRANSFERABLE PRINCIPLE** — Keep local object actions attached, but promote the
current diagnostic object above generic summary metrics.

### LUN-DIST-01 — Distinctive decisions and limits

**OBSERVATION** — Folder micro-objects recur across KPIs and cards; the rest is a
standard sidebar/dashboard grammar.

**INTERPRETATION** — Craft is strong, but the logo-swap test largely succeeds.

**TRANSFERABLE PRINCIPLE** — Borrow system discipline and object consistency, not
the generic dashboard skeleton.

## Signature moves

| Move | Observation | Interpretation | Transfer | Do not copy |
|---|---|---|---|---|
| Folder micro-objects | Same tactile object recurs across contexts | Abstract records gain identity | Develop glyphs for nodes/subsystems/containers | Folder artwork |
| Luminance-first dark mode | Structure survives without hue | Calm long-session use | Neutral surface ladder | Exact charcoal values |
| Stable rail + workbench | Navigation remains fixed across crops | Orientation is durable | Preserve chassis across lenses | Lunor IA |
| Local actions | Share/edit/search stay near objects | Ownership is clear | Attach actions to selected entity | Button styling |
| Compact grid reflow | Tall/wide crops keep axes | Responsive family feels consistent | Define priority-driven reflow | Exact breakpoints |

## Translation decisions

- **Borrow:** neutral dark hierarchy, compact spacing, stable chassis, reusable
  object glyphs, and local actions.
- **Ignore:** greeting, contract KPIs, premium upsell, folder IA, and exact grid.
- **Brand-specific:** Lunor mark, folder artwork, and iconography.
- **Accidental:** several files are duplicate/resized crops; they are one family.
- **Anti-patterns/limitations:** generic sidebar + KPI row; repeated equal cards;
  muted text may fail contrast; product identity is weaker than craft.
