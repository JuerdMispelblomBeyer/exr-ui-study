# Sources

Citation keys used across `1-frameworks/`. Cite by key (`[stappers2017]`), never
by restating the source. One entry per source; add rather than edit.

`tier` records how much weight a claim from this source can carry:

- `primary` — read in full, or a peer-reviewed source read directly.
- `secondary` — reliable summary of a primary source; verify before quoting.
- `industry` — vendor or trade material; useful for context, not for claims.
