# Visual DNA profile

The Visual DNA profile is a compact, comparable model of a reference's design
logic. It is not a mood-board caption. Every value needs one visible evidence
sentence and should describe a relationship, not merely an adjective. Build the
profile only after the detailed analysis; each row cites the observation IDs it
summarizes and introduces no new claims.

## Calibrated axes

Choose the smallest set of axes that explains the reference. Do not fill every
cell with several synonyms.

### Aesthetic

Use a precise compound such as `editorial-technical`, `industrial-instrumental`,
`softly spatial`, `graphic-minimal`, or `material-luxury`. Support it with the
devices producing that aesthetic. Avoid standalone `modern`, `clean`, or
`premium`.

### Personality

Use paired axes where helpful:

- restrained ↔ expressive;
- rational ↔ emotive;
- quiet ↔ assertive;
- precise ↔ organic;
- utilitarian ↔ theatrical;
- familiar ↔ experimental.

State which visible choice creates the position.

### Density

Use `low / medium / high`, then state whether density is uniform or rhythmic.
A sparse orientation zone plus dense evidence region is not simply “medium.”

### Whitespace

Use `compressed / balanced / expansive`, then identify its purpose: focus,
grouping, ceremony, editorial pacing, or unused area.

### Grid

Use `strict / modular / fluid / asymmetric / hybrid`, optionally with inferred
column behavior. Do not assert an exact column count unless visible alignments
support it.

### Typography

Use paired qualities such as `neutral body + expressive display`,
`compact technical`, or `typography-led editorial`. Include hierarchy contrast
as `low / medium / high`.

### Color

Use `monochrome / limited / polychrome`, accent concentration
`low / medium / high`, and temperature or saturation only when material.
Describe role allocation rather than copying hues.

### Geometry

Use `angular / soft / hybrid`, then state enclosure strength and the contrast
between outer and inner forms. “Rounded” alone is insufficient.

### Surfaces

Use `flat / layered / inset / floating / volumetric / hybrid`, then map which
layers appear persistent, selected, or temporary.

### Imagery

Use `absent / supporting / co-dominant / dominant / integrated`, plus treatment:
documentary, rendered, atmospheric, diagrammatic, masked, cropped, or spatial.

### Hierarchy

Use `flat / moderate / steep`, then name the first three reads. Distinguish
information hierarchy from decorative contrast.

### Composition

Use an operative phrase: `single dominant field with attached inspector`,
`editorial split with asymmetrical image mass`, `continuous instrument bed`, or
another relationship visible in the source.

### Distinctiveness

Use `generic / contextual / recognizable / signature-led`, then name the
structural reason. Brand color or logo alone cannot justify `recognizable`.

## Comparison use

When analyzing several sources, align profiles by field and compare mechanisms,
not adjectives. Two references may both be “restrained” while one achieves it
through typographic quiet and the other through low surface contrast; these are
different principles.
