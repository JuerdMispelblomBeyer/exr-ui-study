# Distinctiveness

Distinctiveness is the recognizable expression of product purpose through
composition, content relationships, material behavior, typography, and a small
set of signature moves. It is not novelty, decoration, or trend accumulation.

## Establish the visual thesis

Complete this sentence from rendered evidence:

> This interface feels specific because it organizes **[product object or
> decision]** through **[formal/compositional idea]**, reinforced by
> **[two or three recurring devices]**.

If the sentence can only cite adjectives such as clean, modern, futuristic,
minimal, premium, dark, or bold, the design has no visual thesis.

## Operational tests

### Logo-swap test

Mentally replace the logo and lead accent with those of another B2B SaaS
product. If the design still appears fully plausible, mark it anonymous. Name
the structural features causing this—not the missing logo treatment.

### Thumbnail-memory test

After viewing the screen briefly, look away and describe its silhouette,
dominant object, and one signature relationship. If only “sidebar and cards”
remains, distinctiveness is weak.

### Product-specificity test

Ask whether the content model changes the layout. Real topology, media,
timeline, spatial relationships, comparison, editing, or diagnostic tasks
should produce different compositions. Relabeled generic tiles do not count.

### Signature-move test

Find two or three recurring devices and state what each means. Examples include
an attached detail lens, a continuous dependency path, a particular edge stack,
a diagnostic cursor, or a product-shaped navigation transition. A visual trick
that cannot be assigned meaning is arbitrary decoration.

### Reference-distance test

Compare the current render with inspiration. The intended principles—such as
floating depth, quiet gradients, strong type contrast, or asymmetric massing—
may be visible. The source's exact layout, signature illustration, proprietary
asset, or component arrangement should not be traced. Penalize both literal
copying and superficial imitation.

## Distinctive versus decorative

| Distinctive | Decorative |
|---|---|
| Dominant composition follows the core task | Gradient/blob added behind a generic grid |
| Signature device repeats with semantic meaning | Random glow/overlap applied for visual interest |
| Product data changes shape, density, or flow | Same card anatomy with different labels |
| Typography has a deliberate role in the thesis | Display font applied everywhere |
| Surface hierarchy explains ownership and state | Every panel floats equally |
| Asymmetry reveals priority or sequence | Arbitrary offsets simulate editorial design |

## Correcting anonymity

Do not prescribe more decoration. Identify the product relationship that should
become the composition. Then:

1. enlarge or continuous-map that relationship;
2. demote generic summaries to supporting evidence;
3. remove containers that interrupt the relationship;
4. define two or three meaningful signature devices;
5. reuse those devices across sibling tasks without repeating the same layout;
6. re-run the logo-swap and thumbnail-memory tests.

## Severity

- **Low:** recognizable thesis; only isolated generic components.
- **Moderate:** some product character, but the silhouette and most modules are
  conventional.
- **High:** trends and default dashboard grammar dominate; logo swap succeeds.
- **Critical:** composition appears copied, or the product is represented by
  irrelevant decorative complexity.

High or Critical genericity prevents `PASS` and caps Distinctiveness at 5.
